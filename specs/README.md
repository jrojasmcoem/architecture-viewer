# Especificaciones de Arquitectura Multivendor

Cada funcionalidad futura tiene su propia carpeta con numeración secuencial,
por ejemplo `001-navegacion-diagramas/`. Spec Kit genera allí `spec.md`,
`plan.md`, `tasks.md` y, cuando corresponda, listas de verificación y documentos
de diseño. La secuencia es local a `architecture-viewer/`; no reutiliza los
números ni las especificaciones del directorio `specs/` de la raíz.

Consulta `.specify/memory/constitution.md` antes de crear una especificación.
Este proyecto documenta y presenta diagramas interactivos con datos estáticos;
no describe operaciones reales ni requiere formularios o backend.
